# Ghost

A small cozy 3D platformer about a black cat who is also a little ghost. One night: an apartment, a fire escape,
a roof, a street with a corner shop, an alley and a park. It runs in the browser (Safari on iPhone, iPad and Mac,
or any recent browser) and can be added to the Home Screen.

This repository holds only the published files. Built with three.js and three-mesh-bvh (both MIT, in `vendor/`).
